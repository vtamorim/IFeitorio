# CDU011 – Consultar Histórico de Justificativas de falta

**Ator Primário:** Coordenador.  
**Descrição:** Este caso de uso permite que o Coordenador consulte o histórico de justificativas de falta registradas no sistema.  
**Pré-condições:** Usuário deve estar logado como Coordenador.  
**Pós-condições:** *Nenhuma informação é alterada no sistema.*

## Fluxo Principal

1. O coordenador acessa o sistema com login de coordenador.
2. O coordenador seleciona a opção "Gerenciar Justificativas".
3. O Coordenador seleciona a opção “Consultar Histórico”.
4. O sistema exibe todas as justificativas de falta já realizadas.
