# CDU011 – Consultar Histórico de Justificativas de falta

**Ator Primário:** Coordenador.  
**Descrição:** Permite o coordenador consulte todas as justificativas de falta mandadas.  
**Pré-condições:** Usuário deve está logado como Coordenador.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O coordenador acessa o sistema com login de coordenador.
2. O coordenador seleciona a opção "Gerenciar Justificativas" e, depois, "Consultar Histórico".
3. O sistema exibe todas as justificativas de falta já realizadas.
