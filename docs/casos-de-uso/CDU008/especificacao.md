# CDU008 – Gerenciar Alunos

**Ator Primário:** Coordenador.  
**Descrição:** Permite que a coordenação gerencie os alunos cadastrados no sistema.  
**Pré-condições:** Usuário deve estar logado como Coordenador.    
**Pós-condições:** Dados sobre os alunos podem ser modificados.  

## Fluxo Principal

1. O coordenador acessa o sistema com login de coordenador.
2. O coordenador seleciona a opção "Gerenciar Alunos".
3. O sistema exibe uma lista de alunos.
4. O coordenador seleciona algum aluno.
5. O sistema exibe todas os dados sobre o aluno.
6. O coordenador pode alterá-las, caso necessário.
