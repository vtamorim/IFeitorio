# CDU014 – Consultar Cardápio

**Ator Primário:** Aluno.  
**Descrição:** Permite o aluno consultar o cardápio semanal.  
**Pré-condições:** O Usuário precisa estar cadastrado como Aluno.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O aluno acessa o sistema com o login de aluno.
2. O aluno acessa a opção "Consultar Cardápio".
3. O sistema exibe uma lista de cardápios organizados por período de datas.
4. Para cada cardápio, as informações são apresentadas por tipo de refeição, sendo: Cardápio do Lanche, Cardápio do Almoço e Cardápio do Jantar.
5. Cada tipo de refeição é organizado por data diária.
6. O Cardápio do Lanche é subdividido por turno, contemplando Manhã, Tarde e Noite, com os respectivos itens de cada período.
