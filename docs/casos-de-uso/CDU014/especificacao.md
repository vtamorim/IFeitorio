# CDU014 – Ver Notificações

**Ator Primário:** Aluno.  
**Descrição:** Permite ao aluno ver as suas notificações recebidas.  
**Pré-condições:** O Usuário deve estar cadastrado como Aluno.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O aluno acessa o sistema com o login de aluno.
2. O aluno seleciona a opção de "Ver Notificações".
3. O sistema exibe todas as notificações recebidas pelo aluno.
