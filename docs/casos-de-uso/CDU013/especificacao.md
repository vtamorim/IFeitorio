# CDU013 – Gerar QR-Code

**Ator Primário:** Aluno.  
**Descrição:** Permite ao aluno ver o seu QR-Code de matrícula.  
**Pré-condições:** O Usuário deve estar cadastrado como Aluno.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O aluno seleciona a opção de "Ver QR-Code".
2. O sistema exibe automaticamente o QR-Code do aluno que contém sua matricula.
