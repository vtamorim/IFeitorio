# CDU009 – Gerenciar Restrições

**Ator Primário:** Coordenador.  
**Descrição:** Permite que a coordenação gerencie as restrições cadastradas no sistema (vegetariano, intolerância à lactose, ...).  
**Pré-condições:** Usuário deve está logado como Coordenador.  
**Pós-condições:** Dados sobre as restrições podem ser modificados.  

## Fluxo Principal

1. O coordenador acessa o sistema com login de coordenador.
2. O coordenador seleciona a opção "Gerenciar Restrições".
3. O sistema exibe uma lista de restrições.
4. O coordenador pode editá-las, adicionar ou deletar uma restrição.
5. O sistema salva as alterações realizadas.
