# CDU018 – Ver faltas

**Ator Primário:** Aluno.  
**Descrição:** Permite o aluno ver suas faltas cadastradas em refeições.  
**Pré-condições:** O usuário deve estar cadastrado como aluno.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O aluno acessa o sistema com o login de aluno.
2. O aluno acessa a opção "Ver Faltas".
3. O sistema exibe as faltas do aluno.
