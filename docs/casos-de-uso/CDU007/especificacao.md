# CDU007 – Gerenciar Avaliações

**Ator Primário:** Coordenador.  
**Descrição:** Permite que a coordenação consulte avaliações feitas de alguma refeição.  
**Pré-condições:** Usuário deve está logado como Coordenador.  
**Pós-condições:** Avaliações podem ser excluídas.  

## Fluxo Principal

1. O coordenador acessa o sistema com login de coordenador.
2. O coordenador seleciona a opção "Gerenciar Avaliações".
3. O sistema exibe as refeições e quantas avaliações foram feitas em cada uma.
4. O coordenador seleciona alguma refeição.
5. O sistema exibe todas as avaliações da refeição selecionada, assim como algumas estatísticas sobre elas.
6. O coordenador pode selecionar alguma avaliação em específico para excluí-la.
