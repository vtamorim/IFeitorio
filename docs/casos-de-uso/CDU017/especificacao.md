# CDU017 – Ver Justificativas

**Ator Primário:** Aluno.  
**Descrição:** Permite o Aluno ver suas Justificativas de Falta Cadastradas e seus estados atuais.  
**Pré-condições:** O Usuário precisa estar cadastrado como Aluno.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O aluno acessa o sistema com o login de aluno.
2. O aluno acessa a opção "Ver Justificativas".
3. O sistema exibe todas as justificativas cadastradas, mostrando seus "id", "falta a que se refere", "motivo" e "estado da aprovação".
