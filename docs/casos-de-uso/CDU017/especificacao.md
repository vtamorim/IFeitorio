# CDU017 – Avaliar refeição 

**Ator Primário:** Aluno e Coordenador
**Descrição:** .  Permitir o aluno avaliar a refeição para enviar para o Coordenador
**Pré-condições:** .  A matrícula do aluno estar registrada no sistema.
**Pós-condições:** .  O coordenador receber a avaliação.

## Fluxo Principal

1. O usuario acessa o sistema com o login de aluno/coordenador.
2. O usuario acessa a opção "Avaliar Refeição".
3. O sistema exibirá todas as refeições anteriores.
4. O usuario seleciona uma refeição.
5. O usuario insere os dados ( Nota como obrigatório, e Conteúdo e Título como opcionais)
6. O usuário seleciona o botão "Enviar Avaliação".
7. O sistema registrará os dados para o sistema.
