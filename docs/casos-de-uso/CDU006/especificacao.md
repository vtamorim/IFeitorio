# CDU006 – Gerenciar Justificativa

**Ator Primário:** Coordenador.  
**Descrição:** Permite que a coordenação gerencie as justificativas de falta do almoço.  
**Pré-condições:** O usuário deve estar logado como coordenador.  
**Pós-condições:** A justificativa selecionada terá seu status atualizado para aprovada ou recusada.  

## Fluxo Principal

1. O coordenador seleciona a opção "Gerenciar Justificativas".
2. O sistema exibe um campo para seleção de justificativas pendentes..
3. O coordenador seleciona uma justificativa
4. O sistema exibe as informações do aluno (nome), data da falta, cardápio, tipo da justificativa, motivo e as opções de aprovação ou recusa.
5. O coordenador avalia e define se a justificativa será aceita ou recusada.
6. O coordenador clica no botão "Analisar"
7. O sistema envia uma notificação informando ao aluno sobre a decisão.
