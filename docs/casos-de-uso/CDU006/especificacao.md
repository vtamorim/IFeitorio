# CDU006 – Gerenciar Justificativa

**Ator Primário:** Coordenador.  
**Descrição:** Permite que a coordenação gerencie as justificativas de falta do almoço.  
**Pré-condições:** Usuário deve está logado como Coordenador.  
**Pós-condições:** Justificativas serão aprovadas/desaprovadas.  

## Fluxo Principal

1. O coordenador acessa o sistema com login de coordenador.
2. O coordenador seleciona a opção "Gerenciar Justificativas".
3. O sistema exibe as justificativas pendentes.
4. O administrador avalia e define se a justificativa será aceita ou recusada.
5. O aluno é notificado com a decisão.
