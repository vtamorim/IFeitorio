# CDU00X – Justificar Falta no Almoço
        
**Ator Primário:** Aluno .  
**Descrição:** Permite o Aluno enviar a justificativa para o Coordenador.  
**Pré-condições:** O aluno deve possuir o auxilio do almoço, ter faltado.  
**Pós-condições:** O coordenador receber a justificativa do aluno que a enviou.  

## Fluxo Principal

1. O aluno entra na página de justificativa de forma direta.
2. O aluno insere os dados exigidos (data e o motivo).
3. O aluno seleciona o botão "Enviar justificativa".
4. O sistema registra a justificativa e a envia para o coordenador.

## Fluxo Alternativo 

- **FA1 - Ir para a Página de Justificativa pela notificação**
    
    **Ponto de Inserção:** Antes do passo 1 do Fluxo Principal o aluno entra na página de justificativa pela notificação e o resto segue MUDAR FLUXO ALTERNATIVO
