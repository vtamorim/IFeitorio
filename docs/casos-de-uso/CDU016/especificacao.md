# CDU016 – Consultar Cardápio

**Ator Primário:** Aluno.  
**Descrição:** Permite o aluno consultar o cardápio semanal.  
**Pré-condições:** O Usuário precisa estar cadastrado como Aluno.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O aluno acessa o sistema com o login de aluno.
2. O aluno acessa a opção "Consultar Cardápio".
3. O sistema exibe o cardápio atual e os passados.
