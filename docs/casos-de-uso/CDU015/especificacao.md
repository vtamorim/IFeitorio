# CDU015 – Gerar QR-Code

**Ator Primário:** Aluno.  
**Descrição:** Permite ao aluno ver o seu QR-Code de matricula.  
**Pré-condições:** O Usuário deve estar cadastrado como Aluno.  
**Pós-condições:** *Nenhuma*.  

## Fluxo Principal

1. O aluno acessa o sistema com o login de aluno.
2. O aluno seleciona a opção de "Ver QR-Code".
3. O sistema exibe automaticamente o QR-Code do aluno.
